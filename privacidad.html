Política de privacidad

Aplicación «JARVIS» · Última actualización: 14 de noviembre de 2026

1. Quién usa la aplicación

JARVIS es una aplicación de uso personal. La desarrolla y la usa únicamente su dueño, Roger Sotomayor, con su propia cuenta de Google. No hay otros usuarios y no se ofrece al público.

2. A qué datos accede y para qué

La aplicación solicita acceso a Gmail con dos permisos:

  • gmail.readonly: leer y buscar correos, resumirlos y descargar los adjuntos que el dueño pide.
  • gmail.send: enviar correos, y solo después de que el dueño revise el borrador y lo confirme con su PIN personal. La aplicación nunca envía correos por su cuenta.

Usa estos datos únicamente para dar esas funciones al dueño. No los usa para publicidad, ni para crear perfiles, ni para ningún otro fin.

3. Dónde se procesan y con quién se comparten

Los datos se procesan en un servidor personal controlado por el dueño. No se venden, no se alquilan y no se comparten con terceros, con una sola excepción: para resumir o redactar, el texto necesario de un correo se envía al modelo de inteligencia artificial que usa el asistente (Anthropic, Claude), únicamente para generar la respuesta al dueño.

Los correos y adjuntos descargados se guardan en el servidor personal. El token de acceso se guarda en un archivo con permisos restringidos, fuera del código y de cualquier repositorio.

4. Cumplimiento de la política de datos de usuario de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustarán a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado (Limited Use). En particular:

  • Los datos solo se usan para ofrecer y mejorar las funciones visibles para el dueño descritas arriba.
  • No se transfieren a terceros, salvo lo necesario para prestar esas funciones (el modelo de IA indicado), cumplir la ley o por seguridad.
  • No se usan para publicidad ni para entrenar modelos de IA generalizados.
  • Ninguna persona lee los correos, salvo el propio dueño, o si hace falta por seguridad o por obligación legal.

5. Seguridad adicional

El contenido de los correos se trata siempre como datos y nunca como instrucciones para el asistente. Los correos y adjuntos no se reenvían a direcciones que el dueño no haya escrito, y los adjuntos descargados nunca se ejecutan.

6. Cómo revocar el acceso

El acceso se puede retirar en cualquier momento en myaccount.google.com/permissions, eligiendo la aplicación «JARVIS» y pulsando «Quitar acceso». Al revocarlo, la aplicación deja de poder leer o enviar correos. El dueño también puede borrar en cualquier momento los archivos descargados del servidor.

7. Cambios y contacto

Si esta política cambia, se actualizará esta página con la nueva fecha. Para cualquier consulta, contacto a través de mi perfil de GitHub.
